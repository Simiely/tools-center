# 技术栈 · 精确版本与模块

## 运行时

| 组件 | 版本/要求 | 说明 |
|---|---|---|
| Node.js | ≥ 18(开发 22.x) | 原生 `fetch` / `AbortController` 必需 |
| 第三方依赖 | **零(铁律)** | 全部用 `node:` 内置模块;拒绝无论证的新依赖 |
| 浏览器 | 任意现代浏览器 | 仅访问首页/工具页面 |

## 进程结构

```
server.mjs(主程序,单进程)
├── HTTP 服务 :8080(首页 + /tool/* 反代 + /api/*)
├── 工具子进程:每个 app 型工具一个 spawn 子进程(8100~8199)
└── link 型工具:不 spawn,仅注册表条目
```

## 模块清单(lib/)

| 模块 | 职责 | 关键导出 |
|---|---|---|
| `config.js` | 常量:主端口 8080 / 工具段 8100-8199 / 健康间隔 30s / 代理超时 60s / 日志保留 7 天 / 退避 1s→30s | `CONFIG` |
| `registry.js` | 扫描 `tools/*/tool.json` → 校验(id/type/url/cmd/port/端口冲突)→ `Map<id, ToolSpec>` | `scanTools / reload / get / list` |
| `manager.js` | app 型进程托管:spawn / 崩溃退避拉起 / SIGTERM→5s→SIGKILL / 健康轮询 | `startAll / start / stop / restart / status` |
| `proxy.js` | app 型反代(`/tool/<id>/*` 流式转发);link 型 302;WS 升级预留 | `createProxyHandler(registry)` |
| `logger.js` | 每工具 stdout/stderr → `data/logs/<id>.log`(按天滚动)+ 内存 200 行 | `attach / read` |

## tool.json 契约(摘要)

- `id`(唯一)/ `name` / `desc` / `group` / `icon`
- `type`: `app`(默认)| `link`
- `url`(link 必填)/ `cmd`+`port`(app 必填)/ `cwd` / `env` / `health` / `restart` / `hidden`
- 详见 `DESIGN.md` 第五章

## 数据文件

| 路径 | 内容 | 敏感性 |
|---|---|---|
| `data/logs/*.log` | 工具日志 | 一般 |
| `tools/<id>/` | 工具本体 + 其数据(如 `wb-accounts.json`) | 🔴 工具凭证严禁上传 |
